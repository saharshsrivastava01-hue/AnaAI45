Protocol safety

The server stores public records only. Each claim is checked for a valid ECDSA P-256 signature and SHA-256 key fingerprint. The database enforces one global label per registry. This is an early prototype: no account recovery, transfer, revocation, admin moderation or independent security audit exists. A signed key proves control of that key, not a person's real-world identity or a trademark right.
