ULTRA creates a portable identity record, a cryptographic proof of its contents, alias routing and a resolver page. It works without buying a domain—but it is not a public DNS zone or globally shared registry.

Honest architecture: alice.ultra is an ULTRA namespace label. It resolves through this project's HTTPS page. Public internet-wide DNS resolution requires a registered domain or an ICANN-delegated TLD and DNS infrastructure. No fake .ultra DNS delegation is claimed.

01 · Register identity

Creates a P-256 key pair in your browser and signs the identity record. The private key stays in this browser's IndexedDB; it is not uploaded. Clearing browser data may make the key unavailable. Export your signed record for backup, but note that the public record does not contain the private key.

02 · Resolve & verify

Resolver results appear here. Signature verification checks whether the record was modified after it was signed.

03 · Local registry

Registered identities on this device/browser.

04 · Alias routing

Create short aliases that resolve to an identity record.

05 · Export & import

Export a portable JSON registry containing public keys and signatures. Never share private keys.

07 · Protocol and trust model

Identity record

Normalized label, ULTRA namespace, destination, description, created timestamp, public key, fingerprint, version and signature.

Cryptographic proof

ECDSA P-256 with SHA-256 signs canonical JSON. A resolver can verify the signature using the embedded public key.

Local uniqueness

Availability is checked against this browser's local registry. It is not globally unique until a shared database and atomic uniqueness constraint exist.

Key storage

Non-exportable private CryptoKeys are stored in IndexedDB on this origin. Browser profile loss can make them unrecoverable. This is an experimental prototype, not a certified wallet.

Transport and hosting

HTTPS hosting protects transport. It does not make the namespace part of DNS or provide domain ownership.

Next production layer

Shared Postgres registry, authenticated ownership, row-level security, atomic claims, signed audit events, rate limits, abuse review and replicated resolvers.

Domain technology reality check

A public top-level domain requires formal DNS root delegation and registry operations. ICANN's 2026 new-gTLD application round has a USD 227,000 evaluation fee per application, before possible additional costs; the round closed in August 2026. This prototype is intentionally a free platform namespace, not a workaround for those rules.
