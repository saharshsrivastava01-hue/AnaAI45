A community layer for creator profiles, moderated posts and public discovery.

Ownership security: each new creator profile is bound to an ECDSA P-256 key generated in this browser. Posts must be signed by that same key and are still held for operator approval. The non-exportable private key is stored in this browser's IndexedDB. Clearing browser data or losing this device can permanently remove access; there is no recovery flow yet. The API must be deployed with the D1 migration before these features work.
